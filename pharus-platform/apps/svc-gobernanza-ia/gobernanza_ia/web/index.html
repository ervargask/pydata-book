Inventario de agentes (AI-BOM)

Agentes, integraciones con modelos y servidores MCP descubiertos. Cada uno tiene identidad propia, responsable, nivel de autonomía y vínculos con el RAT, la EIPD y los incidentes.

ActivoTipoModeloDatosAutonomíaRiesgo

Descubrimiento

El inventario se alimenta de forma continua desde varias fuentes. Ninguna lee valores de secretos ni datos personales: solo metadatos, nombres de variables y ubicaciones.

Para desarrollo: la fuente «Repositorios» ya funciona en el demo local (gobernanza-ia escanear <ruta>, análisis AST sin ejecutar código). Las demás son maqueta: cada una debe implementarse como plugin con el mismo contrato que los motores de ciberseguridad (tipo de activo, tiempo máximo, versión de reglas).

Contratos de privacidad

Versión ejecutable del RAT para un agente: finalidades, base de licitud, qué datos puede ver el modelo y cómo, qué herramientas puede usar y adónde viajan los datos. Lo no declarado se bloquea.

Guardrails y trazas
Cada ejecución de un agente gobernado deja una traza: herramientas planificadas y ejecutadas, zona de la acción, resultado de cada guardrail y el riesgo de OWASP que mitigó. Las trazas no guardan datos personales.

Bandeja de aprobaciones
Acciones de agentes en zona ámbar o roja que esperan una persona. Se muestran los argumentos con los datos ya protegidos. Aprobar exige la acción «Verificar manualmente» en el módulo; nada se ejecuta solo.
